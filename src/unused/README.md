# Изолированные React-компоненты

Компоненты в этой папке сохранены на случай осознанного повторного использования. Они исключены из активного приложения, потому что не имеют импортов в `src`, API, тестах или конфигурациях. Каждая пара CSS перемещена вместе с компонентом. Не импортировать напрямую в UI без решения о возвращении функциональности.

| Файл | Причина изоляции | Проверка |
|---|---|---|
| `Unused_AnalyticsPageTracker.jsx` | Не монтируется; route pageview уже отслеживается в `App.jsx`, телефонные/Telegram кнопки имеют собственные события. Глобальный обработчик потенциально дублировал метрики. | Точный basename поиск по `src`, `api`, `server`, `tests`; совпадение было только в файле компонента. |
| `Unused_Clients.jsx` + `.module.css` | Нет импорта/маршрута; витринная секция не подключена в публичных страницах. | Точный поиск имени/пути по runtime-коду и тестам; совпадения вне себя отсутствуют. |
| `Unused_CommercialGallery.jsx` + `.module.css` | Нет импорта/маршрута; карточка коммерческого объекта использует другой отображающий компонент. | Точный поиск имени/пути по runtime-коду и тестам; совпадения вне себя отсутствуют. |

Также удалены пять CSS-модулей, не имеющих ни одного импорта: `ChangeCard.module.css`, `CreateCard.module.css`, `src/pages/Admin.module.css`, `ChangeCommercial.module.css`, `ChangeCommercialPage.module.css`. Одноимённые admin-компоненты остаются активными; найденные модули не импортировались и не содержали маршрутов/логики.
